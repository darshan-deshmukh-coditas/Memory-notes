● Write(docs\adr\0002-overdue-is-computed-not-stored.md)
  ⎿  Wrote 3 lines to docs\adr\0002-overdue-is-computed-not-stored.md
      1 # Overdue is computed at read time, never stored
      2 
      3 The store holds only `open` or `done`. `overdue` is worked out on
         every read from the due date and "today" (the system date, or `-
        -today`). We rejected storing an `overdue` status, because it wou
        ld go stale as days pass and would need a sweep to keep right. Be
        cause "today" is injected, results are repeatable in tests (NFR-M
        2). Status is exclusive: done, overdue or open, so `--status open
        ` hides overdue items. See FRD D1, D44, D54.
